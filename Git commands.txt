Git and GitHub

-> to initialise the repository type git init in cmd of your project directory

-> to create file (type nul > file.txt)

-> to add file to git type git add . or (git add file.txt)

-> to commit with msg type git commit -m "message"

-> to get status type git status

-> to delete file del file.txt

-> to restore git reset (copy the hashcode)



Steps to push project in github

1) git init
2) git remote add origin (github repo link).git
3) git add .
4) git commit -m "Initial commit"
5) git branch -m main
